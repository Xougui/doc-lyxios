# 📚 Lyxios Documentation

Ce dépôt contient le code source et le contenu de la documentation officielle de **Lyxios**, accessible sur [doc.lyxios.fr](https://doc.lyxios.fr/).

La documentation est propulsée par [Astro](https://astro.build/) et [Starlight](https://starlight.astro.build/).

## 🚀 Développement local

### Prérequis
- Node.js (version 22+ requise)
- npm

### Installation et Lancement

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/Xougui/doc-lyxios.git
   cd doc-lyxios
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```
   La documentation sera accessible sur `http://localhost:4321/`.

4. **Tester le build de production**
   ```bash
   npm run build
   ```
