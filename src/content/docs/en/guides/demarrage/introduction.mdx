Welcome to the official documentation of **Lyxios**! 🎉

Lyxios is a multi-purpose Discord bot designed to provide a comprehensive management, moderation, and engagement experience for your server. Highly customizable, it adapts to your specific needs.

## How to configure Lyxios?

Lyxios offers two ways to configure its modules, according to your preference:

### From Discord (`/config` Command)
You can configure everything directly from your server without ever leaving Discord.
Simply run the command:

```txt
/config
```

This command opens an interactive panel allowing you to enable, disable, and configure each module individually (Tickets, Logs, Welcome, etc.).

### From the Online Dashboard
For broader, visual management, a complete web dashboard is also available on our website. Simply log in with your Discord account to manage all your server settings from your browser.

## Exploring the documentation

Use the sidebar menu to navigate across the different guides and modules. Each module has its own dedicated page explaining how it works and how to set it up using the `/config` command.
