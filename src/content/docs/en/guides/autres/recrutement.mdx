## Where to find the recruitment system?

Access it via the `/recrutement` command.

## What is it for?

The recruitment system allows creating complete recruitment forms directly inside Discord with custom inputs, select menus, and logs.

## Navigation & Actions

- <span class="discord-element discord-btn-success"><Plus size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Créer un poste</span>: Create a position.
- <span class="discord-element discord-btn-primary"><Send size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Lancer la campagne</span>: Launch a recruitment campaign.
- <span class="discord-element discord-btn-secondary"><Settings size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Gérer les campagnes</span>: Manage active campaigns.
