Welcome to the Lyxios module configuration center! 
Lyxios offers a wide range of features (Security, Moderation, Community, Tools) to manage and enhance your Discord server.

<Aside type="tip" title="Centralized Control Panel">
All configuration is done via a single command on your server: `/config`.
By typing this command, Lyxios will present an interactive menu categorized into 5 main sections for easy server customization without leaving Discord!
</Aside>
