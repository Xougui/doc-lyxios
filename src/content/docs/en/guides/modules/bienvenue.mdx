## Where to find the welcome module?

You can find the welcome module in the bot's `/config` command.
You can access it in two different ways:
1. By using the `/config` command and selecting the `Welcome` module in the `module` option. (`/config module:Welcome`)
2. By executing the `/config` command and selecting the `Welcome` option from the dropdown menu.

## What is the welcome module for?

The welcome module allows you to warmly welcome your new members by sending a personalized message when a user joins the server.
You can configure this message to be sent in a specific channel, personalize its content with dynamic variables, and attach a beautiful welcome card generated with a custom background image.

---

## Module Configuration

Once you have accessed the welcome panel, here are the different options available to configure your welcome settings:

<Steps>
1. **Enable or disable the module**: Use the <span class="discord-element discord-btn-success">✔️ Enable</span> or <span class="discord-element discord-btn-danger">✖️ Disable</span> button to toggle the module state.
2. **The welcome channel**: In the dropdown menu <span class="discord-element discord-select">Configure the welcome channel <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, select the text channel where the welcome message will be sent. *(Note: You must configure the channel before you can modify the message).*
3. **The welcome message**: Click on the <span class="discord-element discord-btn-success">🛠️ Message</span> button to write your welcome text. You can include several variables (see [the section below](#available-variables-for-the-message)).
4. **The background image**: Click on the <span class="discord-element discord-btn-primary">🖼️ Image</span> button to provide the URL of an image that will serve as the background for the welcome card generated by the bot. If you wish to remove it, use the <span class="discord-element discord-btn-secondary">🗑️ Remove Image</span> button.
5. **Ghost Ping (Optional)**: In the dropdown menu <span class="discord-element discord-select">Configure ghost ping channels <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, you can select up to 5 channels where the new member will be "pinged" (mentioned then the message is instantly deleted). This is very useful to draw the member's attention to the rules or announcements without polluting the channel.
</Steps>

<Aside type="tip" title='Test your configuration!'>
You can check the final rendering by using the <span class="discord-element discord-btn-primary">🧪 Test</span> button in the configuration tab. The bot will simulate your arrival and send you a preview of the message and the Ghost Ping (visible only to you).
</Aside>

## Available variables for the message

To make your welcome message unique and targeted, Lyxios provides several variables that will be automatically replaced by the member's or server's information:

* <Badge text="{user.mention}" variant="note" /> or <Badge text="{user}" variant="note" />: Directly mentions the new member (e.g., @Lyxios).
* <Badge text="{user.name}" variant="note" />: Displays the member's username (without mentioning them).
* <Badge text="{user.id}" variant="note" />: Displays the member's unique identifier (ID).
* <Badge text="{server.name}" variant="note" />: Displays the name of your server.
* <Badge text="{server.member_count}" variant="note" />: Displays the total number of *human* members (bots are not counted) on the server after the arrival.

## About the welcome image

The welcome card is dynamically generated by the bot if you configure a valid image URL.

<Aside type="caution" title="Beware of Discord (CDN) links">
**Never** use image links hosted directly on Discord (links starting with `cdn.discordapp.com` or `media.discordapp.net`). These links are temporary and expire over time. Your welcome image will eventually disappear. Prioritize permanent hosts like **[Imgur](https://imgur.com/)**.
</Aside>

### Image processing by Lyxios
To ensure optimal and aesthetic rendering regardless of the image you provide, the bot applies precise visual processing:

* **Strict Resizing**: The image is resized and cropped cleanly (without distortion) to fit a fixed resolution of **1500x600 pixels**. Plan a landscape format image for better results.
* **Readability Filters**: A slight Gaussian blur as well as a darkened veil (overlay) are applied to the image so that the welcome text stands out perfectly.
* **Avatar Integration**: The member's profile picture is added in a circular format on the left of the image. It is surrounded by a colored border automatically picking up the **dominant color** of your background image.
* **Smart Text Contrast**: The bot calculates the brightness of the text area. If your background is light, the text will be black; if the background is dark, the text will be white, always guaranteeing excellent readability.
* **Displayed Information**: The image contains the title "BIENVENUE" (or "WELCOME" depending on the language), the member's name, a matching separator bar, and a subtitle indicating their position (e.g., "You are the 150th member.").

If the image URL is invalid or inaccessible, the bot is designed not to crash: it will automatically switch to a classic integrated message (Embed) using the bot's dominant color!
