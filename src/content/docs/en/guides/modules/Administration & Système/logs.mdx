## Where to find the logs module?

You will find the logs module in the `/config` command of the bot.
You can access it in two ways:
1. Using direct command: `/config module:Logs`
2. Run `/config`, select **Administration & Management**, then choose **Logs** in the dropdown.

## What is the logs module for?

The **Logs** module keeps a detailed record of all activity on your server. You can choose which events to monitor and which specific text channels will receive alerts (deleted messages, moderation actions, voice channel changes, etc.). The system allows you to create multiple configurations to separate moderation logs from message logs.

## Module Configuration

From the main logs panel, you have access to three quick actions:
* <span class="discord-element discord-btn-success">➕ Add</span>: Manually create a new log channel configuration.
* <span class="discord-element discord-btn-primary">⚡ Quick Setup</span>: Automatically generate all recommended log channels inside a Discord category of your choice.
* <span class="discord-element discord-btn-danger">🗑️ Reset</span>: Clear all log configurations in a single step (with an option to delete the channels).

### Manual Configuration

If you choose to manually configure a log channel, follow these steps:

<Steps>
1. **Select text channel**: Use the dropdown <span class="discord-element discord-select">Select a channel... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> to define where log events will be sent.
2. **Choose global categories**: In <span class="discord-element discord-select">Select categories... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, select event categories (*Messages*, *Moderation*, *Members*, *Server*, *Voice*, *Threads*). All events in these categories are enabled by default.
3. **Refine selection (Optional)**: If you do not want to enable all events in a category, select it in the <span class="discord-element discord-select">Fine-tune a specific category... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> dropdown.
4. **Choose sub-categories (Optional)**: Select specific sub-events in the <span class="discord-element discord-select">Options <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> menu.
5. **Save**: Click <span class="discord-element discord-btn-success">💾 Save</span> (or use quick presets <span class="discord-element discord-btn-primary">✅ Enable all</span> / <span class="discord-element discord-btn-secondary">🚫 Disable all</span>).
</Steps>

<Aside type="tip" title="Channel Separation">
You can configure up to 6 different log channels (e.g., `#logs-messages`, `#logs-moderation`). Using **Quick Setup** configures this recommended layout instantly!
</Aside>

## Interactive Action & Rollback Buttons in Logs

Log messages generated by Lyxios include contextual action buttons that allow moderators and administrators to react immediately:

* <span class="discord-element discord-btn-secondary"><RotateCcw size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Remove timeout</span> / <span class="discord-element discord-btn-secondary"><RotateCcw size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Unban</span>: Instantly roll back an applied sanction.
* <span class="discord-element discord-btn-secondary"><UserX size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Kick</span> / <span class="discord-element discord-btn-danger"><Gavel size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Ban</span>: Take quick moderation actions on targeted members from log alerts.
* <span class="discord-element discord-btn-danger"><Trash2 size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Delete message</span>: Immediately delete a message flagged in log embeds.

## Event Categories

Lyxios allows you to segment your logs across main categories:

* <Badge text="Members" variant="note" />: Member joins, leaves, nickname changes, role updates, and avatars.
* <Badge text="Messages" variant="note" />: Edited messages, deleted messages, bulk deletion (purge), pinned messages, and Ghost Ping detection.
* <Badge text="Moderation" variant="note" />: Warnings, kicks, bans, timeouts, and suspicious activity spike detection.
* <Badge text="Voice Channels" variant="note" />: Voice joins, leaves, moves, server mutes/deafens, and streams/cameras.
* <Badge text="Server" variant="note" />: Server setting updates, creation/deletion/edits of channels, roles, emojis, stickers, invites, and webhooks.
* <Badge text="Threads" variant="note" />: Creation, deletion, and updates of discussion threads.

## Security & Permissions

<Aside type="caution" title="Private Channels">
Make sure to restrict access to your log channels (via Discord permissions) exclusively to your admin and moderation team, as they may contain sensitive information.
</Aside>

Ensure Lyxios has **View Channel**, **Send Messages**, and **Embed Links** permissions in all designated log channels. Without these permissions, event logging will fail.
