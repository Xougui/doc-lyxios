## Where to find the tickets module?

You will find the tickets module in the `/config` command of the bot.
You can access it in two ways:
1. Direct command: `/config module:Tickets`
2. Run `/config`, select **Administration & System**, then choose **Tickets** in the dropdown.

## What is the tickets module for?

The tickets module allows you to create and manage support tickets to track issues, feature requests, and tasks for your server.

---

## Module Configuration

Configured via the `/config` interactive panel:

### 1. Configuration via Dropdown

Using <span class="discord-element discord-select">⚙️ Configurer une option... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>:

**Channels & Roles:**
* **📂 Ticket Category**: Category where new ticket channels will be created.
* **👑 Manager Role**: Role permitted to see and manage tickets.
* **📜 Logs Channel**: Channel where activity logs and transcripts are sent.
* **🎟️ Panel Channel**: Channel where the ticket creation panel message is sent.

**Text & Appearance:**
* **👋 Welcome Message**: Custom welcome message when a ticket opens (`{user}`).
* **🎨 Panel Embed**: Title, Description, Color, and Menu Label.
* **Button Color**: Color of the button.
* **Button Emoji**: Emoji on the creation button.

**Advanced Features:**
* **🔢 Max Tickets/User**: Limit simultaneous tickets per user (1 to 5).
* **📝 Reasons**: Add or remove reasons for opening tickets.
* **⭐ Reviews / Rating**: Rating system on ticket close.
* **🙋‍♂️ Claiming**: Enable or disable ticket claiming by staff.
* **💬 Staff Discussion**: Private thread inside tickets for staff discussion.

### 2. Quick Actions

* <span class="discord-element discord-btn-success">Modify Panel</span>: Send or update the panel message.
* <span class="discord-element discord-btn-secondary"><RefreshCw size={14} style={{ marginRight: '4px' }} /> Refresh</span>: Refresh the UI state.
* <span class="discord-element discord-btn-danger"><PowerOff size={14} style={{ marginRight: '4px' }} /> Disable</span>: Disable the tickets system.

## Ticket Management

### Claiming Tickets (Claim)
Staff members see <span class="discord-element discord-btn-primary">Claim ticket</span>. Clicking it assigns the ticket to that staff member. The button then changes to <span class="discord-element discord-btn-secondary">Unclaim ticket</span>.

### Closing & Transcripts
Clicking <span class="discord-element discord-btn-danger">Close the ticket</span> generates an HTML transcript sent to the user via DM and to the log channel.
