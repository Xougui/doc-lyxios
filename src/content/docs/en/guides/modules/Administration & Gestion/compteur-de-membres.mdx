## Where to find the member counter module?

You will find the member counter module in the `/config` command of the bot.
Direct command: `/config module:Compteur de membres`

## What is the member counter module for?

The member counter module displays real-time member statistics directly in locked channels at the top of your server.

---

## Module Configuration

You can choose among 4 types of counters: **Total**, **Humans**, **Bots**, and **Role**.

### Editing a counter

<Steps>
1. **Enable counter**: Use <span class="discord-element discord-btn-success">✔️ Enable</span> or <span class="discord-element discord-btn-danger">✖️ Disable</span>.
2. **Set channel**: 
    * Click <span class="discord-element discord-btn-primary">➕ Create Channel</span> to create a locked channel automatically.
    * Or use the dropdown <span class="discord-element discord-select">Select an existing channel <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
3. **Customize format**: Click <span class="discord-element discord-btn-secondary">✏️ Edit Format</span> to customize the display text (e.g. `Members: {count}`).
4. **Choose role** *(Role mode only)*: Select the role using <span class="discord-element discord-select">Select role to count <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
</Steps>

<Aside type="caution" title="Discord Rate Limits">
Discord limits channel renaming to **2 updates per 10 minutes** per channel.
</Aside>

---

## Formatting Variables

* <Badge text="{count}" variant="note" />: Displays the member count.
* <Badge text="{role}" variant="note" />: Displays the role name (*Role mode only*).
