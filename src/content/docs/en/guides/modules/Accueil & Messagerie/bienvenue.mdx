## Where to find the welcome module?

You will find the welcome module in `/config`.
Direct command: `/config module:Bienvenue`

## What is the welcome module for?

Warmly welcome new members on your server with customized text messages, dynamic variables, and custom card banners.

---

## Module Configuration

<Steps>
1. **Enable or Disable**: Use <span class="discord-element discord-btn-success">✔️ Enable</span> or <span class="discord-element discord-btn-danger">✖️ Disable</span>.
2. **Welcome channel**: Select the channel using <span class="discord-element discord-select">Configure welcome channel <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
3. **Welcome message**: Click <span class="discord-element discord-btn-success">🛠️ Message</span> to edit your text.
4. **Background Image**: Click <span class="discord-element discord-btn-primary">🖼️ Image</span> (or <span class="discord-element discord-btn-secondary">🗑️ Remove image</span>).
5. **Ghost Ping**: Select up to 5 channels using <span class="discord-element discord-select">Configure ghost ping channels (5 max) <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
</Steps>

<Aside type="tip" title="Test your setup!">
Check your result using the <span class="discord-element discord-btn-primary">🧪 Test</span> button.
</Aside>

---

## Available Variables

* <Badge text="{user.mention}" variant="note" />: Mentions the new member.
* <Badge text="{user.name}" variant="note" />: Username of the member.
* <Badge text="{user.id}" variant="note" />: User ID.
* <Badge text="{server.name}" variant="note" />: Server name.
* <Badge text="{server.member_count}" variant="note" />: Human member count.
