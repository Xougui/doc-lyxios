## Where to find the welcome module?

You will find the welcome module in the `/config` command of the bot.
You can access it in two ways:
1. Direct command: `/config module:Bienvenue`
2. Run `/config`, select the **Reception & Messaging** category, and choose the **Welcome** module in the dropdown.

## What is the welcome module for?

The welcome module warmly greets new members by sending a customized message whenever a user joins your server.
You can configure messages to post in a dedicated channel, format text using dynamic variables, and attach a generated banner card with a custom background image.

---

## Module Configuration

Once in the welcome configuration panel, configure your settings using these steps:

<Steps>
1. **Enable or disable the module**: Use <span class="discord-element discord-btn-success">✔️ Enable</span> or <span class="discord-element discord-btn-danger">✖️ Disable</span> to toggle module state.
2. **Welcome channel**: In the dropdown menu <span class="discord-element discord-select">Configure welcome channel <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, select the text channel where greetings will be sent. *(Note: You must set a channel before editing the message).*
3. **Welcome message**: Click <span class="discord-element discord-btn-success">🛠️ Message</span> to write your welcome text. You can include dynamic variables (see [the section below](#available-variables)).
4. **Background image**: Click <span class="discord-element discord-btn-primary">🖼️ Image</span> to provide an image URL used as background for the welcome card. Use <span class="discord-element discord-btn-secondary">🗑️ Remove image</span> to remove it.
5. **Ghost Ping (Optional)**: In <span class="discord-element discord-select">Configure ghost ping channels (5 max) <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, select up to 5 channels where the new member will be ghost-pinged (mentioned and instantly deleted). This brings immediate attention to rules or announcements without cluttering the chat.
</Steps>

<Aside type="tip" title="Test your setup!">
Preview your layout with the <span class="discord-element discord-btn-primary">🧪 Test</span> button. The bot will simulate a join event and send a private preview of the message, banner, and ghost ping.
</Aside>

## Available Variables

To personalize your greeting, Lyxios provides dynamic variables that automatically resolve to user and server information:

* <Badge text="{user.mention}" variant="note" /> or <Badge text="{user}" variant="note" />: Mentions the new member (e.g., @Lyxios).
* <Badge text="{user.name}" variant="note" />: Displays the member's username (without pinging).
* <Badge text="{user.id}" variant="note" />: Displays the member's unique Discord ID.
* <Badge text="{server.name}" variant="note" />: Displays your server's name.
* <Badge text="{server.member_count}" variant="note" />: Displays total human member count on the server after joining.

## About the Welcome Banner

The welcome card is dynamically generated by the bot whenever a valid image URL is configured.

<Aside type="caution" title="Caution with Discord CDN Links">
Never use direct Discord attachment links (`cdn.discordapp.com` or `media.discordapp.net`). These links are temporary and expire over time, causing your banner to break. Use permanent image hosts like **[Imgur](https://imgur.com/)**.
</Aside>

### Image Processing by Lyxios
To guarantee crisp and legible results regardless of the uploaded background, the bot applies custom image rendering:

* **Strict Resizing**: Images are cropped and resized to a fixed **1500x600 pixels** landscape ratio without stretching.
* **Readability Enhancements**: A subtle Gaussian blur and dark overlay are applied to highlight foreground text.
* **Avatar Integration**: The member's profile picture is rendered inside a circular frame with a border matching the dominant color of your background.
* **Intelligent Text Contrast**: The bot calculates background brightness to switch between white or black typography for maximum readability.
* **Information Overlay**: Banners feature the "WELCOME" headline, member username, divider accent, and join rank (e.g., "You are the 150th member.").

If the image URL becomes unreachable, the bot falls back automatically to a standard Discord Embed using the bot's theme color without crashing.
