¡Bienvenido a la documentación oficial de **Lyxios**! 🎉

Lyxios es un bot de Discord multifunción diseñado para ofrecerte una experiencia completa de administración, moderación y entretenimiento para tu servidor. Altamente personalizable, se adapta a tus necesidades específicas.

## ¿Cómo configurar Lyxios?

Lyxios te ofrece dos opciones para configurar todos sus módulos, según tus preferencias:

### Desde Discord (Comando `/config`)
Puedes configurarlo todo directamente desde tu servidor sin salir de él.
Solo necesitas usar el comando:

```txt
/config
```

Este comando abrirá un panel interactivo que te permitirá activar, desactivar y ajustar cada módulo individualmente (Tickets, Registros, Bienvenida, etc.).

### Desde el Panel Web
Para una gestión más global y visual, también dispones de un panel de control completo en nuestro sitio web. Simplemente inicia sesión con tu cuenta de Discord para gestionar todos los ajustes de tu servidor desde tu navegador.

## Explorar la documentación

Utiliza el menú lateral para navegar por las diferentes guías y módulos. Cada módulo tiene su propia página que explica su funcionamiento y cómo configurarlo a través del comando `/config`.
