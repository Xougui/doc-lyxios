## ¿Dónde encontrar el sistema de reclutamiento?

Accede mediante el comando `/recrutement`.

## ¿Para qué sirve el sistema de reclutamiento?

El sistema de reclutamiento permite crear formularios de postulación directamente en Discord con preguntas personalizadas, menús desplegables y registros.
