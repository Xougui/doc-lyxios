## ¿Qué es el comando `/config-user`?

El comando `/config-user` permite a cada usuario gestionar sus preferencias personales en el bot.

---

## Gestión de preferencias

### Notificaciones de Luckyblocks

Puedes activar o desactivar las notificaciones efímeras al encontrar un Luckyblock.

* **Activadas**: Aparece un mensaje efímero cada vez que descubres un Luckyblock.
* **Desactivadas**: Los Luckyblocks se añaden directa y silenciosamente a tu inventario.
