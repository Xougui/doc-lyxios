## ¿Dónde encontrar el módulo de contador de miembros?

Puedes encontrar el módulo de contador de miembros mediante el comando `/config` del bot.
Puedes acceder de dos formas distintas:
1. Usando el comando directo: `/config module:Compteur de membres`
2. Ejecutando el comando `/config`, seleccionando la categoría **Administration & Système** y el módulo **Compteur** en el menú desplegable.

## ¿Para qué sirve el módulo de contador de miembros?

El módulo de contador de miembros permite mostrar la cantidad de miembros de tu servidor en tiempo real en un canal de voz bloqueado.

---

## Configuración del módulo

Puedes elegir entre 4 tipos de contadores: **Total**, **Humains**, **Bots**, y **Rôle**.

### Editar un contador

<Steps>
1. **Activar el contador**: Usa el botón <span class="discord-element discord-btn-success">✔️ Activer</span> o <span class="discord-element discord-btn-danger">✖️ Désactiver</span>.
2. **Definir el canal**: Haz clic en <span class="discord-element discord-btn-primary">➕ Créer un salon</span> o usa el menú desplegable <span class="discord-element discord-select">Choisir un salon existant <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
3. **Personalizar el nombre**: Haz clic en el botón <span class="discord-element discord-btn-secondary">✏️ Modifier le format</span> (ej: `Membres: {count}`).
</Steps>
