## ¿Dónde encontrar el módulo de contador de miembros?

Encontrarás el módulo de contador de miembros en el comando `/config` del bot.
Puedes acceder a él de dos formas diferentes:
1. Usando el comando `/config` y seleccionando el módulo `Compteur` en la opción `módulo`. (`/config module:Compteur de membres`)
2. Ejecutando el comando `/config` y seleccionando la opción `Compteur` en el menú desplegable.

## ¿Para qué sirve el módulo de contador de miembros?

El módulo de contador de miembros permite mostrar el número de miembros de tu servidor en tiempo real.
Generalmente configurado en un **canal de voz bloqueado**, permite tener una visibilidad constante sobre el crecimiento de tu comunidad en la parte superior de la lista de canales, sin tener que consultar los ajustes del servidor.

## Configuración del módulo

Una vez en el panel de configuración, puedes elegir entre 4 tipos de contadores:

* **Total**: Muestra el número total de miembros (incluidos los bots).
* **Humains**: Muestra solo los miembros humanos.
* **Bots**: Muestra solo el número de robots.
* **Rôle**: Muestra el número de miembros que poseen un rol específico.

### Editar un contador

Después de seleccionar un tipo (ej: "Total"), accedes al menú de edición detallado:

<Steps>
1. **Activar el contador**: Usa el botón <span class="discord-element discord-btn-success">✔️ Activer</span> o <span class="discord-element discord-btn-danger">✖️ Désactiver</span> para controlar la actualización automática.
2. **Definir el canal**: Tienes dos opciones:
    * Haz clic en <span class="discord-element discord-btn-primary">➕ Créer un salon</span>: El bot creará automáticamente un canal de voz bloqueado con los permisos adecuados.
    * O usa el menú desplegable <span class="discord-element discord-select">Choisir un salon existant <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> para seleccionar un canal de voz que ya hayas creado.
3. **Personalizar el nombre**: Haz clic en <span class="discord-element discord-btn-secondary">✏️ Modifier le format</span> para cambiar la apariencia del texto (ej: `Miembros: 150`).
4. **Elegir el rol** *(Mode Rôle uniquement)*: Si configuras un contador de rol, aparecerá un menú desplegable adicional para seleccionar el rol a seguir.
</Steps>

<Aside type="caution" title="Limitaciones de Discord (Rate Limits)">
Discord impone un límite estricto en el cambio de nombre de los canales: **2 modificaciones cada 10 minutos**.
Si ves que el contador no se actualiza inmediatamente después de una llegada o salida, es normal. El bot espera a que se levante el límite de Discord para aplicar el cambio.
</Aside>

## Variables de formato

Para personalizar el nombre del canal, puedes usar variables dinámicas que serán reemplazadas automáticamente:

* <Badge text="{count}" variant="note" />: Muestra el número (ej: `150`). Disponible para **todos** los contadores.
* <Badge text="{role}" variant="note" />: Muestra el nombre del rol seguido (ej: `VIP`). Disponible **únicamente** para el contador de tipo **Rôle**.

**Ejemplos de formatos:**
* `Miembros: {count}` → *Miembros: 150*
* `👥・{count} Humanos` → *👥・142 Humanos*
* `[{role}] : {count}` → *[VIP] : 12*
