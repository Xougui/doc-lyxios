## ¿Dónde encontrar el módulo de captcha?

Puedes encontrar el módulo de captcha mediante el comando `/config` del bot.
Puedes acceder a él de dos formas distintas:
1. Usando el comando directo: `/config module:Captcha`
2. Ejecutando el comando `/config`, seleccionando la categoría **Sécurité & Protection** y finalmente el módulo **Captcha** en el menú desplegable.

## ¿Para qué sirve el módulo de captcha?

El módulo de captcha protege tu servidor contra incursiones (raids), bots y cuentas maliciosas. 
Cuando un nuevo usuario entra al servidor, Lyxios le asigna un rol restrictivo y le pide resolver un desafío visual (un cálculo matemático insertado en una imagen) para obtener acceso completo al servidor.

El módulo cuenta con dos modos de funcionamiento:
* **Mode Strict**: Todos los nuevos miembros deben resolver obligatoriamente el captcha.
* **Mode Ciblé**: Solo las cuentas consideradas sospechosas (cuentas recién creadas o sin foto de perfil) deben resolverlo. El resto entra directamente.

## Configuración del módulo

El panel de configuración del Captcha contiene varias opciones y selectores para adaptar la seguridad a tus necesidades:

<Steps>
1. **Elegir el tipo de captcha**: En el menú desplegable <span class="discord-element discord-select">Choisir le type de captcha <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, elige el modo deseado:
   * <span style={{ display: 'inline-flex', alignItems: 'center', gap: '4px' }}><Lock size={14} /> **Strict**</span>: Verifica a todos los recién llegados.
   * <span style={{ display: 'inline-flex', alignItems: 'center', gap: '4px' }}><Goal size={14} /> **Ciblé**</span>: Verifica únicamente las cuentas sospechosas.
2. **Definir el umbral de edad (Solo Modo Ciblé)**: Si seleccionas el modo Ciblé, haz clic en el botón <span class="discord-element discord-btn-secondary"><Hourglass size={14} style={{ marginRight: '4px' }} /> Seuil Âge</span> para definir la antigüedad mínima de la cuenta en días (por ejemplo `7` días). Las cuentas creadas hace menos de 7 días deberán pasar el captcha.
3. **Configurar el rol restrictivo**: En el selector <span class="discord-element discord-select">Choisir le rôle restrictif (Unverified) <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, selecciona el rol restrictivo asignado a los miembros no verificados. Si no tienes uno, pulsa en <span class="discord-element discord-btn-primary"><Settings size={14} style={{ marginRight: '4px' }} /> Créer & Configurer Permissions</span> para que el bot cree automáticamente el rol `Unverified` y ajuste los permisos de tus canales.
4. **Configurar el canal de verificación**: En el selector <span class="discord-element discord-select">Choisir le salon de vérification <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, selecciona el canal de texto donde se mostrará el captcha o pulsa en <span class="discord-element discord-btn-primary">Créer salon vérif</span> para que el bot cree un canal `#verification`.
5. **Configurar el canal de registros**: En el selector <span class="discord-element discord-select">Choisir le salon de logs <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, selecciona el canal donde se enviarán los resultados (éxitos, fallos y expulsiones).
6. **Activar el módulo**: Una vez configurado el rol y el canal de verificación, pulsa en <span class="discord-element discord-btn-success"><Power size={14} style={{ marginRight: '4px' }} /> Activer le module</span>. Para desactivarlo más tarde, pulsa en <span class="discord-element discord-btn-danger"><PowerOff size={14} style={{ marginRight: '4px' }} /> Désactiver le module</span>.
</Steps>

<Aside type="caution" title="Configuración automática de permisos">
El botón <span class="discord-element discord-btn-primary"><Settings size={14} style={{ marginRight: '4px' }} /> Créer & Configurer Permissions</span> (o *Mettre à jour Permissions*) ajusta automáticamente los permisos de tu servidor para ocultar todos los canales de texto y voz al rol no verificado, manteniendo visible únicamente el canal de verificación.
¡Además, Lyxios aplicará automáticamente estas restricciones a los **nuevos canales** que crees después!

## Funcionamiento para el nuevo usuario

Cuando un miembro debe pasar la verificación:
1. Lyxios le asigna el rol restrictivo definido (ej: `Unverified`).
2. El bot envía un mensaje en el canal de verificación mencionando al usuario con el botón **Démarrer la vérification / Start Verification**.

<Image src={captchaFirstMessageImage} alt="Mensaje de invitación a la verificación" style={{ margin: '1rem 0' }} />

3. Al hacer clic, el bot genera una imagen con una operación matemática (ej: `5 + 10 - 2 = ?`) junto a una cuadrícula de 5 botones con emoticonos de frutas o animales.
4. La imagen indica la correspondencia entre cada resultado posible y un emoticono (ej: `13 ➔ 🍎`, `15 ➔ 🍌`).
5. El miembro debe pulsar el emoticono que corresponda a la respuesta correcta.

<Image src={captchaEmojisImage} alt="Pantalla del captcha matemático con emoticonos" style={{ margin: '1rem 0' }} />

### Reglas y seguridad

* **Tiempo límite**: El usuario dispone de **30 minutos** para iniciar y resolver el captcha. De lo contrario, es expulsado automáticamente (kick) para liberar espacio y evitar cuentas inactivas.
* **Límite de intentos**: El usuario dispone de **3 intentos**. Si se equivoca 3 veces, es expulsado automáticamente del servidor.
* **Limpieza automática**: Si el usuario abandona el servidor mientras el captcha está activo, Lyxios elimina automáticamente su mensaje de verificación para mantener limpio el canal.
* **Seguridad Anti-Bot**: Los botones utilizan identificadores únicos aleatorios (UUIDs) en cada captcha para evitar que scripts automatizados adivinen o repitan clics.
* **Mecanismo de seguridad (Fail-Safe)**: Si el bot no tiene permisos suficientes para asignar el rol restrictivo al llegar el miembro, este es **expulsado de inmediato por seguridad** para evitar que acceda al servidor sin verificación.

## Registros de verificación

Si configuras un canal de registros, el bot enviará notificaciones detalladas en Embeds para cada suceso relevante:

* **🔐 Captcha Validé** (Verde): Indica el miembro verificado, su ID único y la fecha de creación de su cuenta de Discord.
* **❌ Captcha Échoué** (Rojo): Indica el fallo de la verificación (al agotar los 3 intentos) antes de la expulsión.
* **👢 Membre Expulsé (Captcha Timeout)** (Naranja): Se genera cuando un miembro supera los 30 minutos sin verificarse, causando su expulsión automática.
