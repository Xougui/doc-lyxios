¡Bienvenido al centro de configuración de módulos de Lyxios!
Lyxios ofrece una amplia variedad de funciones (Seguridad, Moderación, Comunidad, Herramientas) para gestionar y dinamizar tu servidor de Discord.

<Aside type="tip" title="El Panel de Control Centralizado">
Toda la configuración se realiza mediante un único comando en tu servidor: `/config`.
Al escribir este comando, Lyxios mostrará un menú interactivo por categorías para ajustar fácilmente los parámetros sin salir de Discord.
</Aside>
