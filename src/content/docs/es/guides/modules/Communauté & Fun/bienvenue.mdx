## ¿Dónde encontrar el módulo de bienvenida?

Puedes acceder con el comando directo: `/config module:Bienvenue` o seleccionando **Communauté & Fun** y luego el módulo **Bienvenue**.

## ¿Para qué sirve el módulo de bienvenida?

El módulo de bienvenida permite dar una cálida recepción a tus miembros con mensajes personalizados, variables dinámicas y una imagen de bienvenida.

---

## Configuración del módulo

<Steps>
1. **Activar o desactivar**: Usa el botón <span class="discord-element discord-btn-success">✔️ Activer</span> o <span class="discord-element discord-btn-danger">✖️ Désactiver</span>.
2. **Canal de bienvenida**: En el menú desplegable <span class="discord-element discord-select">Configurer le salon de bienvenue <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, selecciona el canal de texto.
3. **El mensaje**: Haz clic en el botón <span class="discord-element discord-btn-success">🛠️ Message</span> para editar el texto.
4. **La imagen de fondo**: Haz clic en el botón <span class="discord-element discord-btn-primary">🖼️ Image</span> o elimina la imagen con <span class="discord-element discord-btn-secondary">🗑️ Supprimer l'image</span>.
5. **Ghost Ping**: En el menú <span class="discord-element discord-select">Configurer les salons du ghost ping <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>.
</Steps>

<Aside type="tip" title="¡Prueba tu configuración!">
Puedes verificar el resultado usando el botón <span class="discord-element discord-btn-primary">🧪 Tester</span> en el panel de configuración.
</Aside>
