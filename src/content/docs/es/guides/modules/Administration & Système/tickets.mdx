## ¿Dónde encontrar el módulo de tickets?

Puedes encontrar el módulo de tickets mediante el comando `/config` del bot.
Puedes acceder de dos formas:
1. Usando el comando directo: `/config module:Tickets`
2. Ejecutando el comando `/config`, seleccionando la categoría **Administration & Gestion** y el módulo **Tickets**.

## ¿Para qué sirve el módulo de tickets?

El módulo de tickets permite crear y gestionar tickets para hacer seguimiento de problemas, peticiones y tareas en tu servidor.

---

## Configuración del módulo

Se configura desde el panel interactivo de `/config`:

### 1. Configuración desde el menú desplegable

Usando <span class="discord-element discord-select">⚙️ Configurer une option... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>:

**Canales y Roles:**
* **📂 Catégorie Tickets**: Categoría de Discord donde se crearán los nuevos tickets.
* **👑 Rôle Manager**: Rol con permisos para ver y gestionar los tickets.
* **📜 Salon Logs**: Canal de texto donde el bot enviará el historial y las transcripciones.
* **🎟️ Salon Panel**: Canal donde se enviará el mensaje con el panel de creación.

**Textos y Apariencia:**
* **👋 Message Bienvenue**: Mensaje de bienvenida al abrir un ticket (`{user}`).
* **🎨 Embed Panel**: Título, Descripción, Color y Etiqueta del menú.
* **🎨 Couleur Bouton**: Color del botón.
* **🎫 Emoji Bouton**: Emoji del botón.

**Funciones Avanzadas:**
* **🔢 Max Tickets/User**: Límite de tickets abiertos simultáneamente por usuario (1 a 5).
* **📝 Gérer Motifs**: Añadir o eliminar razones de apertura.
* **⭐ Avis / Notation**: Sistema de valoración al cerrar el ticket.
* **🙋‍♂️ Prise en charge**: Activar o desactivar la opción de "claim" por el personal.
* **💬 Discussion Staff**: Hilo privado reservado al personal dentro del ticket.
* **⚙️ Mode d'ouverture**: Modo automático o manual.

### 2. Acciones Rápidas

* <span class="discord-element discord-btn-success">🚀 Modifier Panel</span>: Envía o actualiza el mensaje del panel.
* <span class="discord-element discord-btn-secondary"><RefreshCw size={14} style={{ marginRight: '4px' }} /> Rafraîchir</span>: Actualiza la interfaz con los últimos ajustes.
* <span class="discord-element discord-btn-danger"><PowerOff size={14} style={{ marginRight: '4px' }} /> Désactiver</span>: Desactiva el sistema de tickets.

## Gestión de Tickets

### Atender Tickets (Claim)
El personal ve el botón <span class="discord-element discord-btn-primary">🙋‍♂️ Prendre en charge</span>. Al pulsar en él, se asigna el ticket y se restringe la intervención de otros miembros.

### Modo de apertura manual
El personal valida las solicitudes mediante los botones <span class="discord-element discord-btn-success">✅ Ouvrir</span> o <span class="discord-element discord-btn-danger">❌ Fermer</span>.

### Cierre y Transcripción
Al pulsar <span class="discord-element discord-btn-danger">🔒 Fermer le ticket</span>, el bot genera un archivo `.html` enviándolo al usuario por MD y al canal de registros.
