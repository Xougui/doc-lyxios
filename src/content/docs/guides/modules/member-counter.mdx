## Où trouver le module de compteur de membres ?

Vous trouverez le module de compteur de membres dans la commande `/config` du bot.
Vous pouvez y accéder de deux façons différentes :
1. En utilisant la commande `/config` et en sélectionnant le module `Compteur` dans l'option `module`. (`/config module:Compteur de membres`)
2. En effectuant la commande `/config` et en sélectionnant l'option `Compteur` dans le menu déroulant.

## À quoi sert le module de compteur de membres ?

Le module de compteur de membres permet d'afficher le nombre de membres de votre serveur en temps réel.
Généralement configuré sur un **salon vocal verrouillé**, il permet d'avoir une visibilité constante sur la croissance de votre communauté en haut de la liste des salons, sans avoir à consulter les paramètres du serveur.

## Configuration du module

Une fois dans le panneau de configuration, vous pouvez choisir parmi 4 types de compteurs :

* **Total** : Affiche le nombre total de membres (y compris les bots).
* **Humains** : Affiche uniquement les membres humains.
* **Bots** : Affiche uniquement le nombre de robots.
* **Rôle** : Affiche le nombre de membres possédant un rôle spécifique.

### Éditer un compteur

Après avoir sélectionné un type (ex: "Total"), vous accédez au menu d'édition détaillé :

<Steps>
1. **Activer le compteur** : Utilisez le bouton <span style={{ backgroundColor: '#248046', color: '#fff', padding: '0.15em 0.4em', borderRadius: '0.25rem', fontSize: '0.85em', fontWeight: '600', whiteSpace: 'nowrap' }}>✔️ Activer</span> ou <span style={{ backgroundColor: '#DA373C', color: '#fff', padding: '0.15em 0.4em', borderRadius: '0.25rem', fontSize: '0.85em', fontWeight: '600', whiteSpace: 'nowrap' }}>✖️ Désactiver</span> pour contrôler la mise à jour automatique.
2. **Définir le salon** : Vous avez deux choix :
    * Cliquez sur <span style={{ backgroundColor: '#5865F2', color: '#fff', padding: '0.15em 0.4em', borderRadius: '0.25rem', fontSize: '0.85em', fontWeight: '600', whiteSpace: 'nowrap' }}>➕ Créer un salon</span> : Le bot créera automatiquement un salon vocal verrouillé avec les permissions adéquates.
    * Ou utilisez le menu déroulant <span style={{ backgroundColor: '#2e2f35', border: '1.5px solid #43444a', color: '#fff', padding: '0.15em 0.4em', borderRadius: '0.25rem', fontSize: '0.85em', fontWeight: '600', whiteSpace: 'nowrap', display: 'inline-flex', alignItems: 'center' }}>Choisir un salon existant <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> pour sélectionner un salon vocal que vous avez déjà créé.
3. **Personnaliser le nom** : Cliquez sur <span style={{ backgroundColor: '#4f545c', color: '#fff', padding: '0.15em 0.4em', borderRadius: '0.25rem', fontSize: '0.85em', fontWeight: '600', whiteSpace: 'nowrap' }}>✏️ Modifier le format</span> pour changer l'apparence du texte (ex: `Membres: 150`).
4. **Choisir le rôle** *(Mode Rôle uniquement)* : Si vous configurez un compteur de rôle, un menu déroulant supplémentaire apparaîtra pour sélectionner le rôle à suivre.
</Steps>

<Aside type="caution" title="Limitations de Discord (Rate Limits)">
Discord impose une limite stricte sur le renommage des salons : **2 modifications toutes les 10 minutes**.
Si vous voyez que le compteur ne se met pas à jour immédiatement après une arrivée ou un départ, c'est normal. Le bot attend que la limite de Discord soit levée pour appliquer le changement.
</Aside>

## Variables de formatage

Pour personnaliser le nom du salon, vous pouvez utiliser des variables dynamiques qui seront remplacées automatiquement :

* <Badge text="{count}" variant="note" /> : Affiche le nombre (ex: `150`). Disponible pour **tous** les compteurs.
* <Badge text="{role}" variant="note" /> : Affiche le nom du rôle suivi (ex: `VIP`). Disponible **uniquement** pour le compteur de type **Rôle**.

**Exemples de formats :**
* `Membres: {count}` → *Membres: 150*
* `👥・{count} Humains` → *👥・142 Humains*
* `[{role}] : {count}` → *[VIP] : 12*
