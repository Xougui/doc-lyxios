Bienvenue dans le centre de configuration des modules de Lyxios ! 
Lyxios propose une multitude de fonctionnalités (Sécurité, Modération, Animation, Outils) pour gérer et dynamiser votre serveur Discord. 

<Aside type="tip" title="Le Panneau de Configuration Centralisé">
Toute la magie s'opère via une seule commande sur votre serveur : `/config`.
En tapant cette commande, Lyxios vous présentera un menu déroulant interactif classé par catégories. Vous pourrez y paramétrer l'intégralité de votre serveur facilement, sans jamais avoir à quitter Discord !
</Aside>
