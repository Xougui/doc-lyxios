## Où trouver le module des logs ?

Vous trouverez le module des logs dans la commande `/config` du bot.
Vous pouvez y accéder de deux façons différentes :
1. En utilisant la commande directe : `/config module:Logs`
2. En effectuant la commande `/config`, puis en sélectionnant la catégorie **Administration & Gestion** et enfin le module **Logs** dans le menu déroulant.

## À quoi sert le module des logs ?

Le module de **Logs** permet de garder une trace détaillée de toute l'activité de votre serveur. Vous pouvez définir quels événements surveiller et dans quels salons spécifiques envoyer les alertes (messages supprimés, modération, changements de vocaux, etc.). Le système vous permet de créer plusieurs configurations différentes, par exemple pour séparer les logs de modération des logs de messages.

## Configuration du module

Depuis le panneau principal des logs, vous disposez de trois actions rapides :
* <span class="discord-element discord-btn-success">➕ Ajouter</span> : Créer manuellement une nouvelle configuration de salon de logs.
* <span class="discord-element discord-btn-primary">⚡ Config. rapide</span> : Générer automatiquement l'ensemble des salons de logs recommandés au sein d'une catégorie Discord de votre choix.
* <span class="discord-element discord-btn-danger">🗑️ Réinitialiser</span> : Effacer l'ensemble de vos configurations de logs en une seule étape (avec option de suppression des salons).

### Configuration manuelle

Si vous choisissez de configurer manuellement un salon, voici les étapes à suivre :

<Steps>
1. **Sélectionner le salon textuel** : Utilisez le menu déroulant <span class="discord-element discord-select">Sélectionnez un salon... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> pour définir dans quel salon textuel les événements seront envoyés.
2. **Choisir les catégories globales** : Dans le menu déroulant <span class="discord-element discord-select">Sélectionnez les catégories... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, choisissez la ou les catégories d'événements que vous souhaitez activer (ex: *Messages*, *Modération*, *Membres*, etc.). Par défaut, tous les événements de ces catégories seront activés.
3. **Affiner votre sélection (Optionnel)** : Si vous ne souhaitez pas activer tous les événements d'une catégorie, un nouveau menu déroulant <span class="discord-element discord-select">Affiner... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> apparaîtra. Sélectionnez-y la catégorie à modifier.
4. **Choisir les sous-catégories (Optionnel)** : Un dernier menu déroulant <span class="discord-element discord-select">Options <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> apparaîtra, vous permettant de choisir précisément les événements à logger pour la catégorie sélectionnée (au lieu de l'option "Tout").
5. **Sauvegarder** : Cliquez sur le bouton <span class="discord-element discord-btn-success">💾 Sauvegarder</span> pour enregistrer votre configuration. Vous pouvez également utiliser les boutons rapides <span class="discord-element discord-btn-primary">✅ Tout activer</span> ou <span class="discord-element discord-btn-secondary">🚫 Tout désactiver</span>.
</Steps>

<Aside type="tip" title='Séparation des salons'>
Lyxios permet de créer jusqu'à 6 configurations différentes. Nous vous recommandons de les utiliser pour créer des salons dédiés (par exemple : `#logs-messages`, `#logs-modération`) afin d'éviter de surcharger un seul salon avec trop d'informations. La **Configuration rapide** permet d'installer ce découpage recommandé en un seul clic !
</Aside>

## Boutons d'Action & Rollback dans les Logs

Sur les messages de logs envoyés par Lyxios, des boutons d'action contextuels et de modération directe permettent aux modérateurs et administrateurs de réagir instantanément sans quitter le salon :

* <span class="discord-element discord-btn-secondary"><RotateCcw size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Annuler l'exclusion temporaire</span> / <span class="discord-element discord-btn-secondary"><RotateCcw size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Débannir</span> : Permet de réaliser un rollback immédiat sur une sanction appliquée.
* <span class="discord-element discord-btn-secondary"><UserX size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Expulser</span> / <span class="discord-element discord-btn-danger"><Gavel size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Bannir</span> : Modération rapide sur un membre ciblé dans une alerte.
* <span class="discord-element discord-btn-danger"><Trash2 size={14} style={{ marginRight: '4px', verticalAlign: 'middle' }} /> Supprimer le message</span> : Permet de supprimer immédiatement un message signalé par les logs.

## Catégories d'événements

Lyxios vous permet de segmenter vos logs selon différentes catégories principales. Voici les événements surveillés :

* <Badge text="Membres" variant="note" /> : Arrivées, départs, changements de pseudos, mises à jour des rôles, modification d'avatar global et d'avatar de serveur (avec liens HD et aperçus visuels).
* <Badge text="Messages" variant="note" /> : Messages modifiés, messages supprimés, suppression en masse (purge), épinglages/désépinglages détaillés (avec auteur, aperçu du message, pièces jointes et lien direct) et détection des Ghost Pings.
* <Badge text="Modération" variant="note" /> : Avertissements (warns), expulsions (kicks), bannissements (bans), expulsions temporaires (timeouts) et détection des pics d'activité suspects.
* <Badge text="Salons Vocaux" variant="note" /> : Connexions, déconnexions, déplacements, mutes/sourdines serveur et streams/caméras.
* <Badge text="Serveur" variant="note" /> : Modifications des paramètres du serveur, créations, modifications ou suppressions de salons, rôles, emojis, stickers, invites et webhooks.
* <Badge text="Threads" variant="note" /> : Création, modification et suppression de fils de discussion.

## Sécurité et Permissions

<Aside type="caution" title="Salons Privés">
Assurez-vous de bien restreindre l'accès de vos salons de logs (via les permissions Discord) à votre équipe d'administration et de modération uniquement, car ils peuvent contenir des informations sensibles.
</Aside>

Assurez-vous que Lyxios possède bien les permissions de **Voir le salon**, d'**Envoyer des messages** et d'**Intégrer des liens** dans les salons de logs que vous avez définis. Sans ces permissions, le bot ne pourra pas transmettre les événements.
