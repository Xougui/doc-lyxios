## Où trouver le module de tickets ?

Vous trouverez le module de tickets dans la commande `/config` du bot.
Vous pouvez y accéder de deux façons différentes :
1. En utilisant la commande directe : `/config module:Tickets`
2. En effectuant la commande `/config`, puis en sélectionnant la catégorie **Administration & Système** et enfin le module **Tickets** dans le menu déroulant.

## À quoi sert le module de tickets ?

Le module de tickets permet de créer et gérer des tickets pour suivre les problèmes, les demandes de fonctionnalités et les tâches au sein de votre projet.
Il offre une interface simple pour créer des tickets, les assigner à des membres de l'équipe.

## Configuration du module

Le système de tickets de Lyxios est entièrement configurable via un tableau de bord interactif centralisé. Une fois dans le module via `/config`, vous accéderez à une interface composée d'un menu déroulant principal et de quelques boutons d'action rapide.

### 1. Paramétrage via le Menu Déroulant

Toute la configuration se fait depuis le menu déroulant principal <span class="discord-element discord-select">⚙️ Configurer une option... <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>. 
En sélectionnant une option, vous ouvrirez un formulaire ou un sous-menu pour la paramétrer :

**Salons et Rôles :**
*   **📂 Catégorie Tickets** : La catégorie Discord dans laquelle les nouveaux salons de tickets seront créés.
*   **👑 Rôle Manager** : Le rôle qui aura la permission de voir et gérer les tickets. Les administrateurs y ont accès par défaut.
*   **📜 Salon Logs** : Un salon textuel où le bot enverra l'historique des actions (ouverture, fermeture, transcript).
*   **🎟️ Salon Panel** : Le salon où le message de création de ticket (le Panel) sera envoyé aux membres.

**Textes et Apparence :**
*   **👋 Message Bienvenue** : Personnalisez le message envoyé à l'ouverture du ticket. Utilisez `{user}` pour mentionner le membre.
*   **🎨 Embed Panel** : Modifiez le Titre, la Description et la Couleur globale du panel de création.
*   **🎨 Couleur Bouton** : Changez la couleur du bouton de création du ticket sur le panel.
*   **🎫 Emoji Bouton** : Changez l'emoji affiché sur le bouton de création du ticket.

**Fonctionnalités avancées :**
*   **🔢 Max Tickets/User** : Limitez le nombre de tickets ouverts simultanément par un même utilisateur.
*   **📝 Gérer Motifs** : Ajoutez ou supprimez des raisons d'ouverture (ex: *Support*, *Partenariat*). Si vous définissez plusieurs motifs, le panel affichera un menu déroulant plutôt qu'un simple bouton.
*   **⭐ Avis / Notation** : Activez ou désactivez le système de notation à la fermeture du ticket.
*   **🙋‍♂️ Prise en charge** : Activez ou désactivez la possibilité pour votre équipe de "claim" (prendre en charge) un ticket.
*   **💬 Discussion Staff** : Activez ou désactivez la création automatique d'un fil de discussion (Thread) privé réservé au staff à l'intérieur du ticket.
*   **⚙️ Mode d'ouverture** : Basculez entre un mode "Auto" (le panel est géré par le bot) ou "Manuel".

<Aside type="tip" title="Plusieurs panels ?">
Actuellement, le module gère un panel principal par serveur. Vous pouvez utiliser le système de **Motifs** (menu déroulant) pour centraliser toutes les demandes (Support, Recrutement, Commercial) au même endroit.
</Aside>

### 2. Actions Rapides

Sous le menu déroulant principal, vous disposez également de boutons d'action directs :

*   <span class="discord-element discord-btn-success">🚀 Modifier Panel</span> : Envoie ou met à jour immédiatement le message de création de ticket dans le salon configuré.
*   <span class="discord-element discord-btn-secondary">🔄 Rafraîchir</span> : Met à jour l'affichage de l'interface avec les dernières configurations sauvegardées.
*   <span class="discord-element discord-btn-danger">✖️ Désactiver</span> : Supprime totalement la configuration du module de la base de données.

## Gestion des Tickets

Une fois un ticket ouvert, plusieurs fonctionnalités s'offrent à votre équipe et à l'utilisateur.

### Prise en charge (Claim)

*(Note : Cette fonctionnalité peut être activée ou désactivée dans la configuration des **Textes & Options**)*

Les membres du staff (Rôle Manager) voient un bouton <span class="discord-element discord-btn-primary">🙋‍♂️ Prendre en charge</span> dans le ticket.

* **Action** : Lorsqu'un membre du staff clique dessus, il s'assigne le ticket.
* **Effet** : Le bot modifie les permissions pour que **seul** ce membre du staff (et l'utilisateur) puisse répondre. Les autres membres du rôle Manager ne pourront plus parler dans le salon du ticket, évitant la confusion. Les administrateurs du serveur peuvent cependant toujours parler.
* **Libération** : Le bouton change alors en <span class="discord-element discord-btn-secondary">🔓 Libérer le ticket</span> pour permettre à nouveau à toute l'équipe d'intervenir.

### Fermeture et Transcript

Lorsqu'un ticket est terminé, cliquez sur <span class="discord-element discord-btn-danger">🔒 Fermer le ticket</span>.

1. **Génération du Transcript** : Le bot génère un fichier `.html` contenant tout l'historique de la conversation. *Si le fichier dépasse 8 Mo, une version allégée (images sous forme de liens) est générée.*
2. **Envoi DM** : L'utilisateur à l'origine du ticket reçoit ce fichier en message privé, accompagné d'un récapitulatif.
3. **Logs** : Le transcript est également envoyé dans le salon de logs configuré.
4. **Suppression** : Le salon du ticket est supprimé après quelques secondes.

<Aside type="note" title="Notation du support">
*(Note : Ce système d'évaluation peut être activé ou désactivé dans la configuration des **Textes & Options**)*

Après la fermeture, l'utilisateur reçoit en message privé une demande de notation (de 1 à 5 étoiles ⭐). Cette note est ensuite envoyée dans votre salon de logs pour vous aider à suivre la qualité de votre support.
</Aside>

## Commandes Utiles

En plus des boutons, plusieurs commandes slash sont disponibles pour gérer les tickets actifs :

<CardGrid>
  <Card title="/ticket-add" icon="add-document">
    **Ajouter un membre ou un rôle**
    Permet d'ajouter exceptionnellement une personne au ticket actuel.
    *Usage : `/ticket-add target:@User`*
  </Card>
  <Card title="/ticket-remove" icon="close">
    **Retirer un membre**
    Retire l'accès au ticket à un utilisateur spécifique.
    *Usage : `/ticket-remove target:@User`*
  </Card>
  <Card title="/ticket-rename" icon="pencil">
    **Renommer le ticket**
    Change le nom du salon du ticket en cours. Utile pour organiser les demandes.
    *Usage : `/ticket-rename name:nouveau-nom`*
  </Card>
  <Card title="/ticket-reset" icon="setting">
    **Réinitialiser les permissions**
    Remet les permissions du salon à leur état d'origine (utile si les permissions ont été modifiées manuellement par erreur).
    *Usage : `/ticket-reset`*
  </Card>
</CardGrid>
