## Où trouver le module de bienvenue ?

Vous trouverez le module de bienvenue dans la commande `/config` du bot.
Vous pouvez y accéder de deux façons différentes :
1. En utilisant la commande directe : `/config module:Bienvenue`
2. En effectuant la commande `/config`, puis en sélectionnant la catégorie **Communauté & Fun** et enfin le module **Bienvenue** dans le menu déroulant.

## À quoi sert le module de bienvenue ?

Le module de bienvenue permet d'accueillir chaleureusement vos nouveaux membres en envoyant un message personnalisé lorsqu'un utilisateur rejoint le serveur.
Vous pouvez configurer ce message pour qu'il soit envoyé dans un canal spécifique, personnaliser son contenu grâce à des variables dynamiques, et y attacher une magnifique carte de bienvenue générée avec une image de fond personnalisée.

## Configuration du module

Une fois que vous avez accédé au panneau de bienvenue, voici les différentes options disponibles pour paramétrer votre accueil :

<Steps>
1. **Activer ou désactiver le module** : Utilisez le bouton <span class="discord-element discord-btn-success">✔️ Activer</span> ou <span class="discord-element discord-btn-danger">✖️ Désactiver</span> pour basculer l'état du module.
2. **Le canal de bienvenue** : Dans le menu déroulant <span class="discord-element discord-select">Configurer le salon de bienvenue <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, sélectionnez le salon textuel dans lequel le message d'accueil sera envoyé. *(Note : Vous devez configurer le salon avant de pouvoir modifier le message).*
3. **Le message de bienvenue** : Cliquez sur le bouton <span class="discord-element discord-btn-success">🛠️ Message</span> pour rédiger votre texte d'accueil. Vous pouvez y inclure plusieurs variables (voir [la section ci-dessous](#exemple-de-carte-de-bienvenue)).
4. **L'image de fond** : Cliquez sur le bouton <span class="discord-element discord-btn-primary">🖼️ Image</span> pour fournir l'URL d'une image qui servira de fond à la carte de bienvenue générée par le bot. Si vous souhaitez la retirer, utilisez le bouton <span class="discord-element discord-btn-secondary">🗑️ Supprimer l'image</span>.
5. **Ghost Ping (Optionnel)** : Dans le menu déroulant <span class="discord-element discord-select">Configurer les salons du ghost ping <ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>, vous pouvez sélectionner jusqu'à 5 salons dans lesquels le nouveau membre sera "ping" (mentionné puis le message est supprimé instantanément). C'est très utile pour attirer l'attention du membre vers le règlement ou les annonces sans polluer le salon.
</Steps>

<Aside type="tip" title='Testez votre configuration !'>
Vous pouvez vérifier le rendu final en utilisant le bouton <span class="discord-element discord-btn-primary">🧪 Tester</span> dans l'onglet de configuration. Le bot simulera votre arrivée et vous enverra un aperçu du message et du Ghost Ping (visible uniquement par vous).
</Aside>

## Variables disponibles pour le message

Pour rendre votre message de bienvenue unique et ciblé, Lyxios met à votre disposition plusieurs variables qui seront automatiquement remplacées par les informations du membre ou du serveur :

* <Badge text="{user.mention}" variant="note" /> ou <Badge text="{user}" variant="note" /> : Mentionne directement le nouveau membre (ex: @Lyxios).
* <Badge text="{user.name}" variant="note" /> : Affiche le nom d'utilisateur du membre (sans le mentionner).
* <Badge text="{user.id}" variant="note" /> : Affiche l'identifiant (ID) unique du membre.
* <Badge text="{server.name}" variant="note" /> : Affiche le nom de votre serveur.
* <Badge text="{server.member_count}" variant="note" /> : Affiche le nombre total de membres *humains* (les bots ne sont pas comptés) sur le serveur après l'arrivée.

## À propos de l'image de bienvenue

La carte de bienvenue est générée dynamiquement par le bot si vous configurez une URL d'image valide. 

<Aside type="caution" title="Attention aux liens Discord (CDN)">
N'utilisez **jamais** de liens d'images hébergées directement sur Discord (liens commençant par `cdn.discordapp.com` ou `media.discordapp.net`). Ces liens sont temporaires et expirent avec le temps. Votre image de bienvenue finira par disparaître. Privilégiez des hébergeurs permanents comme **[Imgur](https://imgur.com/)**.
</Aside>

### Traitement de l'image par Lyxios
Pour garantir un rendu optimal et esthétique peu importe l'image que vous fournissez, le bot applique un traitement visuel précis :

* **Redimensionnement strict** : L'image est redimensionnée et recadrée proprement (sans déformation) pour s'adapter à une résolution fixe de **1500x600 pixels**. Prévoyez une image au format paysage pour un meilleur résultat.
* **Filtres de lisibilité** : Un léger flou gaussien ainsi qu'un voile assombri (overlay) sont appliqués sur l'image pour que le texte d'accueil ressorte parfaitement.
* **Intégration de l'Avatar** : La photo de profil du membre est ajoutée dans un format circulaire à gauche de l'image. Elle est entourée d'une bordure colorée reprenant automatiquement la **couleur dominante** de votre image de fond.
* **Contraste intelligent du texte** : Le bot calcule la luminosité de la zone de texte. Si votre fond est clair, le texte sera noir ; si le fond est sombre, le texte sera blanc, garantissant toujours une excellente lisibilité.
* **Informations affichées** : L'image contient le titre "BIENVENUE" (ou "WELCOME" selon la langue), le nom du membre, une barre de séparation assortie, et un sous-titre indiquant sa position (ex: "Tu es le 150ème membre.").

Si l'URL de l'image est invalide ou inaccessible, le bot est conçu pour ne pas planter : il basculera automatiquement sur un message intégré (Embed) classique en utilisant la couleur dominante du bot !
