## Où trouver le module Blacklist Kick ?

Le module Blacklist Kick est accessible directement dans l'interface Discord :
1. En utilisant la commande directe : `/config module:Blacklist Kick`
2. En exécutant `/config`, en sélectionnant la catégorie **Sécurité & Protection**, puis en choisissant le module **Blacklist Kick** dans le menu déroulant.

## À quoi sert le module Blacklist Kick ?

Le module **Blacklist Kick** renforce la protection de votre serveur en empêchant les membres malveillants identifiés par l'équipe de modération globale de Lyxios de s'installer sur votre serveur.

Lorsqu'un utilisateur rejoint votre serveur, Lyxios vérifie instantanément si son identifiant figure dans la base de données de blacklist globale :
* Si le module est **activé** et que l'utilisateur est blacklisté, il est **immédiatement expulsé** (kick) du serveur.
* Un message privé lui est envoyé pour lui notifier son expulsion, la raison officielle, l'identifiant du modérateur responsable ainsi que le numéro de dossier de blacklist.
* Le message privé inclut également un lien d'invitation vers le serveur d'appel afin qu'il puisse contester sa sanction s'il estime avoir été sanctionné par erreur.

<Aside type="note" title="Blacklist Globale et Sécurité">
La blacklist de Lyxios référence les comptes ayant commis des infractions graves (raids, arnaques, usurpations, tentatives de hack) sur l'ensemble du réseau de serveurs protégés par le bot.
</Aside>

## Configuration du module

Le panneau de configuration du module Blacklist Kick est conçu pour être simple et instantané :

<Steps>
1. **Activer l'expulsion automatique** : Cliquez sur le bouton <span class="discord-element discord-btn-success"><Power size={14} style={{ marginRight: '4px' }} /> Activer l'expulsion</span>. Le statut passe immédiatement à **Activé**.
2. **Désactiver l'expulsion automatique** : Si vous souhaitez suspendre les expulsions automatiques, cliquez sur le bouton <span class="discord-element discord-btn-danger"><PowerOff size={14} style={{ marginRight: '4px' }} /> Désactiver l'expulsion</span>. Le statut repasse à **Désactivé**.
3. **Retourner au menu** : Cliquez sur <span class="discord-element discord-btn-secondary"><ChevronLeft size={14} style={{ marginRight: '4px' }} /> Retour</span> pour revenir au menu principal de la catégorie Sécurité & Protection.
</Steps>

<Aside type="caution" title="Permissions requises">
Pour que le bot puisse expulser les membres blacklistés lors de leur arrivée :
- Le bot doit posséder la permission Discord **Expulser des membres** (`Kick Members`).
- Le rôle de Lyxios dans les paramètres de votre serveur Discord doit être positionné **plus haut** dans la hiérarchie que les rôles des utilisateurs à expulser.
</Aside>

## Commandes complémentaires

En complément de l'expulsion automatique à la jointure, plusieurs commandes permettent de gérer et vérifier la blacklist sur votre serveur :

* `/check-blacklist recherche:<membre/id/numéro>` : Vérifie si un utilisateur donné ou un identifiant est répertorié dans la blacklist.
* `/liste-blacklist mode:Serveur` : Affiche la liste des membres actuellement présents sur votre serveur qui sont répertoriés dans la blacklist globale.
* `/ban-blacklist` : Permet de bannir en masse tous les utilisateurs présents dans la blacklist globale se trouvant sur votre serveur.
