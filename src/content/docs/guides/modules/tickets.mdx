## Où trouver le module de tickets ?

Vous trouverez le module de tickets dans la commande `/config` du bot.
Vous pouvez y accéder de deux façons différentes :
1. En utilisant la commande `/config` et en sélectionnant le module `Tickets` dans l'option `module`. (`/config module:Tickets`)
2. En effectuant la commande `/config` et en sélectionnant l'option `Tickets` dans le menu déroulant.

## À quoi sert le module de tickets ?

Le module de tickets permet de créer et gérer des tickets pour suivre les problèmes, les demandes de fonctionnalités et les tâches au sein de votre projet.
Il offre une interface simple pour créer des tickets, les assigner à des membres de l'équipe.

## Configuration du module

Le système de tickets de Lyxios est entièrement configurable via un tableau de bord interactif. Une fois le module activé, vous aurez accès à plusieurs menus pour personnaliser l'expérience.

### 1. Salons et Rôles

C'est la première étape essentielle pour que le système fonctionne. Cliquez sur le bouton **Salons & Rôles** pour définir :

<Steps>
1. **Catégorie Tickets** : La catégorie Discord dans laquelle les nouveaux salons de tickets seront créés.
2. **Rôle Manager** : Le rôle qui aura la permission de voir et gérer les tickets (ex: *Support*, *Modérateur*). Les administrateurs ont accès par défaut.
3. **Salon Logs** : Un salon textuel où le bot enverra l'historique des actions (ouverture, fermeture, renommage, etc.).
4. **Salon Panel** : Le salon où le message de création de ticket (le Panel) sera envoyé aux membres.
</Steps>

### 2. Textes et Options

Dans le menu **Textes & Options**, vous pouvez affiner le comportement du bot :

* **Max Tickets** : Limitez le nombre de tickets ouverts simultanément par un même utilisateur (de 1 à 5).
* **Message de Bienvenue** : Personnalisez le message envoyé automatiquement à l'ouverture du ticket. Vous pouvez utiliser la variable `{user}` pour mentionner le membre.
* **Gérer les Motifs** : Ajoutez des raisons d'ouverture (ex: *Support Technique*, *Partenariat*, *Plainte*).
    * *Si vous définissez plusieurs motifs, un menu déroulant sera affiché sur le panel.*
    * *Si vous ne mettez aucun motif ou un seul, un simple bouton sera affiché.*
* **Embed Panel** : Personnalisez l'apparence du message du panel (Titre, Description, Couleur) pour qu'il corresponde à l'identité de votre serveur.

### 3. Déployer le Panel

Une fois la configuration terminée, cliquez sur le bouton <span class="discord-element discord-btn-success">🚀 Modifier Panel</span> (ou "Envoyer Panel") pour publier ou mettre à jour le message de création de ticket dans le salon configuré.

## Gestion des Tickets

Une fois un ticket ouvert, plusieurs fonctionnalités s'offrent à votre équipe et à l'utilisateur.

### Prise en charge (Claim)

Les membres du staff (Rôle Manager) voient un bouton <span class="discord-element discord-btn-primary">🙋‍♂️ Prendre en charge</span> dans le ticket.

* **Action** : Lorsqu'un membre du staff clique dessus, il s'assigne le ticket.
* **Effet** : Le bot modifie les permissions pour que **seul** ce membre du staff (et l'utilisateur) puisse répondre. Les autres membres du rôle Manager ne recevront plus de notifications pour ce ticket, évitant la confusion.
* **Libération** : Le bouton change alors en <span class="discord-element discord-btn-secondary">🔓 Libérer le ticket</span> pour permettre à nouveau à toute l'équipe d'intervenir.

### Fermeture et Transcript

Lorsqu'un ticket est terminé, cliquez sur <span class="discord-element discord-btn-danger">🔒 Fermer le ticket</span>.

1. **Génération du Transcript** : Le bot génère un fichier `.html` contenant tout l'historique de la conversation (messages, images, etc.).
2. **Envoi DM** : L'utilisateur à l'origine du ticket reçoit ce fichier en message privé, accompagné d'un récapitulatif.
3. **Logs** : Le transcript est également envoyé dans le salon de logs configuré.
4. **Suppression** : Le salon du ticket est supprimé après quelques secondes.

<Aside type="note" title="Notation du support">
Après la fermeture, l'utilisateur reçoit en message privé une demande de notation (de 1 à 5 étoiles ⭐). Cette note est ensuite envoyée dans votre salon de logs pour vous aider à suivre la qualité de votre support.
</Aside>

## Commandes Utiles

En plus des boutons, plusieurs commandes slash sont disponibles pour gérer les tickets actifs :

<CardGrid>
  <Card title="/ticket-add" icon="add-user">
    **Ajouter un membre ou un rôle**
    Permet d'ajouter exceptionnellement une personne au ticket actuel.
    *Usage : `/ticket-add target:@User`*
  </Card>
  <Card title="/ticket-remove" icon="close">
    **Retirer un membre**
    Retire l'accès au ticket à un utilisateur spécifique.
    *Usage : `/ticket-remove target:@User`*
  </Card>
  <Card title="/ticket-rename" icon="pencil">
    **Renommer le ticket**
    Change le nom du salon du ticket en cours. Utile pour organiser les demandes.
    *Usage : `/ticket-rename name:nouveau-nom`*
  </Card>
  <Card title="/ticket-reset" icon="refresh">
    **Réinitialiser les permissions**
    Remet les permissions du salon à leur état d'origine (utile si les permissions ont été modifiées manuellement par erreur).
    *Usage : `/ticket-reset`*
  </Card>
</CardGrid>

## Foire aux questions

**Pourquoi le transcript ne contient pas certaines images ?**
Si le fichier de transcript dépasse 8 Mo (limite de Discord pour les fichiers sans Nitro), le bot génère une version "allégée" où les images sont des liens au lieu d'être intégrées directement.

**Puis-je avoir plusieurs panels de tickets ?**
Actuellement, le module gère un panel principal par serveur. Cependant, vous pouvez utiliser le système de **Motifs** (menu déroulant) pour centraliser toutes les demandes (Support, Recrutement, Commercial) au même endroit.

**Que se passe-t-il si je supprime le rôle Manager ?**
Si le rôle configuré est supprimé du serveur, seuls les administrateurs pourront voir et gérer les tickets jusqu'à ce qu'un nouveau rôle soit configuré.
