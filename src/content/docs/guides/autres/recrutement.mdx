## Où trouver le système de recrutement ?

Vous trouverez le système de recrutement dans la commande `/recrutement` du bot.

## À quoi sert le système de recrutement ?

Le système de recrutement permet de créer et administrer des campagnes de candidatures directement sur Discord avec des formulaires interactifs (menus déroulants, cases à cocher, boutons radio et champs texte), des critères d'éligibilité automatiques et un suivi centralisé dans un salon de logs.

---

## Se repérer dans le menu

Lors de l'exécution de la commande `/recrutement`, vous trouverez 5 actions possibles :

- <span class="discord-element discord-select">Sélectionnez un poste à configurer...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Permet de sélectionner un poste existant à modifier *(si un poste ne contient aucune question, il apparaîtra avec la mention `(Incomplet)` et l'icône <Ban size={14} style={{ display: 'inline', verticalAlign: 'middle', marginRight: '4px', marginTop: '-2px' }} />)*.
- <span class="discord-element discord-btn-success"><Plus size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Créer un poste</span> : Permet de créer un nouveau poste de recrutement.
- <span class="discord-element discord-btn-primary"><Send size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Lancer la campagne</span> : Permet de lancer une campagne de recrutement en ouvrant un ou plusieurs postes configurés sur une même annonce.
- <span class="discord-element discord-btn-secondary"><Settings size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Gérer les campagnes</span> : Permet d'administrer les campagnes actives (modifier la date de fin ou clôturer un poste).
- <span class="discord-element discord-btn-secondary"><Globe size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Configuration globale</span> : Permet de définir les rôles gestionnaires appliqués par défaut aux nouveaux postes.

## Configurer le système

### Créer un poste

Quand vous cliquez sur le bouton <span class="discord-element discord-btn-success"><Plus size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Créer un poste</span>, configurez les sélecteurs suivants :

<Steps>
1. <span class="discord-element discord-select">Sélectionnez le rôle...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Rôle Discord attribué au poste visé. <Badge text="Obligatoire" variant="danger" />
2. <span class="discord-element discord-select">Sélectionnez le salon de logs...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Salon privé où seront envoyées les candidatures pour examen. <Badge text="Obligatoire" variant="danger" />
3. <span class="discord-element discord-select">Rôles autorisés à gérer les candidatures (optionnel)...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Rôles autorisés à accepter ou refuser les candidatures dans les logs.
</Steps>

<Aside type="tip">
Si vous ne définissez aucun rôle gestionnaire spécifique, seuls les administrateurs du serveur pourront accepter ou refuser les candidatures.
</Aside>

Validez ensuite via le bouton <span class="discord-element discord-btn-success"><Plus size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Créer le poste</span>.

### Gérer un poste

En sélectionnant un poste existant dans le menu principal, vous accédez à ses réglages détaillés :

- <span class="discord-element discord-btn-danger"><PowerOff size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Désactiver</span> / <span class="discord-element discord-btn-success"><Power size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Activer</span> : Active ou désactive le poste.
- <span class="discord-element discord-btn-secondary"><List size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Gérer les questions</span> : Ouvre l'interface d'ajout et d'organisation des questions du formulaire.
- <span class="discord-element discord-btn-secondary"><Settings size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Conditions d'accès</span> : Définit les critères d'éligibilité préalables requis pour pouvoir postuler.
- <span class="discord-element discord-btn-secondary"><SquarePen size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Modifier salon/rôle</span> : Modifie le rôle ciblé, le salon de logs et les gestionnaires autorisés.
- <span class="discord-element discord-btn-danger"><Trash2 size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Supprimer le poste</span> : Supprime définitivement le poste et ses questions.

#### Conditions d'accès

Le bouton <span class="discord-element discord-btn-secondary"><Settings size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Conditions d'accès</span> permet de filtrer automatiquement les candidats avant qu'ils ne puissent remplir le formulaire :

- <span class="discord-element discord-select">Rôles requis (au moins l'un d'entre eux)...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Permet de choisir jusqu'à 10 rôles requis. Le candidat doit posséder au moins l'un d'entre eux pour être éligible.
- <span class="discord-element discord-btn-success"><Power size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Exiger Tag</span> / <span class="discord-element discord-btn-danger"><PowerOff size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Désactiver Tag</span> : Exige que le membre porte le Tag de guilde/clan officiel du serveur sur Discord.
- <span class="discord-element discord-btn-secondary"><SquarePen size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Modifier ancienneté</span> : Ouvre une boîte de dialogue pour définir :
  - **Jours minimum sur le serveur** : Ancienneté minimale sur votre serveur (`0` pour désactiver).
  - **Jours minimum compte Discord** : Âge minimal du compte Discord (`0` pour désactiver).
- <span class="discord-element discord-btn-secondary"><ChevronLeft size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Retour</span> : Valide et revient à l'écran du poste.

<Aside type="note">
Si un candidat ne respecte pas l'un des critères configurés, un message éphémère lui indique précisément les conditions non remplies et sa candidature est immédiatement bloquée.
</Aside>

#### Gérer les questions

Dans le menu de gestion des questions :
- Cliquez sur <span class="discord-element discord-btn-success"><Plus size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Ajouter une question</span> pour créer une question.
- Sélectionnez une question dans la liste pour paramétrer son composant (texte court, paragraphe long, menu déroulant, cases à cocher, boutons radio), ses choix et son caractère obligatoire.

#### Modifier salon/rôle

Le bouton <span class="discord-element discord-btn-secondary"><SquarePen size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Modifier salon/rôle</span> permet de mettre à jour le rôle cible, le salon de logs et jusqu'à 10 rôles gestionnaires autorisés. Validez avec <span class="discord-element discord-btn-success"><Save size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Enregistrer</span> ou quittez avec <span class="discord-element discord-btn-secondary"><ChevronLeft size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Annuler</span>.

## Lancer la campagne

Le bouton <span class="discord-element discord-btn-primary"><Send size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Lancer la campagne</span> permet de publier l'annonce de recrutement :

<Steps>
1. **Sélectionnez le salon d'annonce** dans le sélecteur de salon dédié.
2. **Sélectionnez le ou les postes** dans <span class="discord-element discord-select">Sélectionnez le ou les postes à ouvrir...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span>. Vous pouvez cocher plusieurs postes simultanément pour regrouper plusieurs recrutements dans une annonce unique.
3. **Choisissez la mention** via le sélecteur global (`Aucune`, `@everyone`, `@here`) ou un rôle spécifique.
4. **Personnalisez l'annonce** via <span class="discord-element discord-btn-secondary"><SquarePen size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Modifier l'Embed / Durée</span> :
   - Titre et description de l'annonce.
   - Durée de validité en jours.
   - Nombre de places disponibles : valeur globale ou répartition par poste séparée par des virgules ou retours à la ligne (ex: `2, 5`).
5. **Publiez la campagne** en cliquant sur <span class="discord-element discord-btn-success"><Send size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Lancer la Campagne</span>.
</Steps>

Chaque poste ouvert dans la campagne disposera de son propre bouton d'action <span class="discord-element discord-btn-success"><Send size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Postuler : [Nom du rôle]</span> sur le message de l'annonce.

---

## Gérer les campagnes actives

Dans l'onglet <span class="discord-element discord-btn-secondary"><Settings size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Gérer les campagnes</span> :

- Choisissez la campagne active à administrer dans le menu déroulant.
- <span class="discord-element discord-btn-secondary"><SquarePen size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Modifier la durée</span> : Ajuste la date et l'heure de clôture.
- <span class="discord-element discord-btn-danger"><Square size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Mettre fin à la campagne</span> : Clôture le poste sélectionné. Si plusieurs postes partagent l'annonce, seul le bouton du poste clôturé est retiré. Dès que tous les postes d'un message sont clos ou expirés, l'annonce bascule automatiquement au statut `Clôturée` et retire les boutons.

<Aside type="tip">
Une tâche automatique vérifie l'expiration des campagnes chaque minute pour clôturer sans intervention les postes arrivés à terme.
</Aside>

## Configuration globale

Le bouton <span class="discord-element discord-btn-secondary"><Globe size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Configuration globale</span> permet de définir les rôles gestionnaires par défaut attribués aux nouveaux postes :

- <span class="discord-element discord-select">Sélectionnez les rôles par défaut...<ChevronDown size={14} style={{ marginLeft: '4px' }} /></span> : Permet de sélectionner jusqu'à 10 rôles gestionnaires.
- <span class="discord-element discord-btn-success"><Save size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Enregistrer</span> : Sauvegarde cette sélection pour les futurs postes créés.
- <span class="discord-element discord-btn-danger"><RefreshCw size={14} strokeWidth={3} style={{ marginRight: '4px' }} />Appliquer à tous</span> : Sauvegarde la sélection et écrase la configuration des gestionnaires sur **l'ensemble des postes existants**.
