Bienvenue dans la documentation officielle de **Lyxios** ! 🎉

Lyxios est un bot Discord multifonctions conçu pour vous offrir une expérience complète d'administration, de modération et d'animation pour votre serveur. Hautement personnalisable, il s'adapte à vos besoins spécifiques.

## ⚙️ Comment configurer Lyxios ?

Lyxios vous offre deux possibilités pour configurer l'ensemble de ses modules, selon vos préférences :

### 1. Depuis Discord (Commande `/config`)
Vous pouvez tout configurer directement depuis votre serveur sans jamais le quitter.
Il vous suffit d'utiliser la commande :

```txt
/config
```

Cette commande ouvrira un panel interactif vous permettant d'activer, désactiver et paramétrer chaque module individuellement (Tickets, Logs, Bienvenue, etc.).

### 2. Depuis le Dashboard en Ligne
Pour une gestion plus globale et visuelle, vous disposez également d'un tableau de bord complet sur notre site web. Connectez-vous simplement avec votre compte Discord pour gérer tous les paramètres de votre serveur depuis votre navigateur.

## 📚 Explorer la documentation

Utilisez le menu latéral pour naviguer dans les différents guides et modules. Chaque module possède sa propre page expliquant son fonctionnement et comment le paramétrer via la commande `/config`.
